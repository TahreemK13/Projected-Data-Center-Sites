AI Regulation and Data Center Siting

We predicted which US counties host a data center, first from infrastructure alone, then with state AI and data center legislation added. This page shows where the model expects data centers, where policy changes that expectation, and how both compare with the national lab forecast that uses no policy data.

Read with care
  • These are statistical associations. Nothing shows that a law itself caused a siting decision.
  • Policy features are set by state. Every county in a state shares them & policy changes follow state lines.
  • Existing data centers coming from OpenStreetMap include facilities of every size.
  • PNNL modeled 37 states. Hatched counties have no PNNL forecast, which is different from a forecast of none.
